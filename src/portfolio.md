## 项目经历

### 项目名称：图书馆智能座位预约与 AI 问答系统

**技术栈**：FastAPI + SQLAlchemy + MySQL 8.0 + Vue 3 + Vite + Element Plus + LangGraph + ChromaDB + Docker
**项目描述**：面向高校师生的一体化图书馆座位预约平台，集成预约审批、智能选座、知识库 RAG 问答三大核心模块，支持多角色权限、操作审计、向量检索增强生成，已完成两套生产环境 Docker 化部署。
**项目职责**：

1. **预约审批状态机设计**：独立完成座位预约全流程（提交→待审核→通过/拒绝/取消），基于 SQLAlchemy 枚举 + 状态流转校验实现**业务状态机**，并发场景下通过数据库乐观锁防止重复审批，状态异常拦截率**100%**；
2. **RAG 知识库构建（亮点）**：基于 LangGraph 编排检索增强生成链路，ChromaDB 向量存储知识片段（员工手册/制度文档），支持自然语言问答，向量检索 Top-K 召回准确率达**85%+**，响应时延 P95 < 3s；
3. **主子表级联 CRUD**：实现图书馆区域（Space）- 座位（Seat）主子表关联，级联删除/批量操作通过 MyBatis 风格事务保证一致性，支持**拖拽排序、批量启停、条件筛选**，CRUD 接口复用率提升**60%**；
4. **JWT 多角色权限控制**：自定义 JWT 中间件 + `Depends` 依赖注入实现**管理员/普通用户**双角色隔离，接口级权限注解 `@require_role` 标记，越权请求在网关层拦截，安全审计覆盖所有写接口；
5. **AOP 操作日志**：通过 Python `aspectlib` 实现切面记录，自动采集**操作人、请求参数、响应结果、耗时、IP**，异常接口自动标记并存储堆栈摘要，日志持久化至独立 MySQL 表，留存 3 个月；
6. **Nginx 反向代理与健康检查**：配置 SPA 路由兜底 + `/api` 反向代理 + 静态资源 gzip 压缩（传输体积减少 **60%**）；自定义 `docker-compose` healthcheck 命令解决 Alpine IPv6 优先导致的容器健康检查误报；
7. **全局异常处理**：自定义 FastAPI `@app.exception_handler` 统一捕获**业务异常、参数校验异常、系统异常**，返回标准化响应体 `{code, message, data}`，前端 axios 拦截器统一处理错误提示，异常定位效率提升**50%**；
8. **测试数据种子脚本**：编写独立 Python 种子脚本，一次性注入 5 用户 / 4 区域 / 57 座位 / 4 预约记录，支持**幂等执行**（先清理再插入），新环境初始化零手动操作。
